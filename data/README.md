# Image data

For the image-fitting study I used the 14 example `TEM00_z_*.jpg` files from the
[DataLab laser-beam profiling tutorial](https://datalab-platform.com/en/intro/tutorials/laser_beam.html).
The original JPEG archive is not stored in this repository.

Download `laser_beam.zip` from the link above and place it in this folder,
or run `python download_source_images.py` from the project root.
The archived fit results are available under `outputs/image_analysis/`.
